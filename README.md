 APEX v4 — AI Trading & Automation Ecosystem

**APEX v4** — бұл қарапайым трейдинг боты емес. Бұл — Python, Жасанды интеллект (AI) және автоматизация технологияларын біріктірген толыққанды экосистема.

## 🚀 Негізгі мүмкіндіктері
- **Multi-AI Ensemble:** LLM (Groq), XGBoost, RL (PPO) және Wyckoff логикасын біріктіретін шешім қабылдау жүйесі.
- **Shazam Pattern Matching (FAISS):** 10 жылдық тарихи деректердің ішінен Фурье (Fourier) арқылы ұқсас паттерндерді миллисекундта табу.
- **FastAPI Webhook Server:** TradingView-ден сыртқы сигналдарды қабылдауға арналған API.
- **Telegram Interface & AI Agent:** Жүйемен табиғи тілде сөйлесу, фильтрлерді өзгерту және статус алу.
- **Risk Management:** Күнделікті шығынды шектеу, динамикалық Stop-Loss және Take-Profit.

## 🛠️ Технологиялар
- **Language:** Python 3.10+
- **AI & ML:** Groq API (LLM), XGBoost, Stable-Baselines3 (PPO), Scikit-learn
- **Web & API:** FastAPI, Uvicorn, Requests
- **Integrations:** MetaTrader 5 (MT5), Telegram Bot API
